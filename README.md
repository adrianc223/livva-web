# livva-web

Public landing page for **Livva** ("Uniendo comunidades") — pitch, pricing tiers, and a lead-capture contact form. Next.js 16 (App Router) + React 19 + Tailwind CSS v4. No database, no auth.

Live: **https://livva-web.vercel.app**

See [CLAUDE.md](./CLAUDE.md) for how the project is structured (page sections, lead capture, deployment, SEO/accessibility) and [docs/ROADMAP.md](./docs/ROADMAP.md) for deferred work.

```bash
npm install
npm run dev
```
